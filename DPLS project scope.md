# PROJECT SCOPE (DPLS)

The project covers the design, development, testing, and deployment of a Departmental Project Library System.

The system will provide:

## User Management

- Administrator login
- Student login
- Supervisor login
- Password authentication
- User profile management
## Project Repository

- Upload project reports (PDF/DOCX)
- Upload project abstract
- Upload source code (ZIP)
- Edit project information
- Delete project records
- View project details
## Metadata Management

The system will manage:

- Project title
- Student author
- Supervisor
- Year
- Programming language
- Keywords
- Project category
## Search Module

## Users can search by:

- Project title
- Author
- Supervisor
- Programming language
- Academic year
- Keywords
## Access Control

The system will implement three user roles:

Administrator

- Full system control
- User management
- Project approval
- Report generation
Supervisor

- Review uploaded projects
- View projects
- Manage metadata
Student

- Upload projects
- Search projects
- View approved projects
